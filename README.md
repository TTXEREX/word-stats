# Word Stats

Консольная утилита на Python: считает статистику текстового файла и сохраняет отчёт в CSV.

## Что считает

- количество строк, слов, уникальных слов и символов;
- топ-10 самых частых слов (служебные и слова короче трёх букв отбрасываются);
- отчёт `*.csv` рядом с исходным файлом, открывается в Excel.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.

```
python main.py sample.txt
```

Пример вывода:

```
File: sample.txt
        lines: 4
        words: 92
       unique: 71
   characters: 631

Top words:
 1. начинается       3
 2. проект           3
 3. первый           2

Report: sample.csv
```

Отчёт:

```
word;count
начинается;3
проект;3
```

## Структура

```
main.py      логика: чтение файла, подсчёт, запись отчёта
sample.txt   пример входных данных
```

## Как это устроено

Файл читается целиком через `pathlib`, слова вытаскиваются регулярным выражением `[а-яёa-z]+`,
частота считается `collections.Counter`. Отчёт пишется в CSV с разделителем `;` и BOM,
чтобы русский текст корректно открывался в Excel.
